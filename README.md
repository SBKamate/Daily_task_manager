# ✅ Daily Task Manager

A simple and user-friendly **Daily Task Manager** website designed to help users organize, manage, and track their daily tasks efficiently.

## 📌 About the Project

**Daily Task Manager** is a web-based task management application that allows users to create and manage their daily tasks.

The project provides a simple interface for adding tasks, viewing tasks, and keeping track of completed and pending activities.

This project was developed to practice **Java, HTML, CSS, JavaScript, and Bootstrap** while building a practical web application.

## ✨ Features

* ➕ Add new tasks
* 📝 View daily tasks
* ✅ Mark tasks as completed
* ❌ Delete tasks
* 📋 Manage pending and completed tasks
* 📱 Responsive design
* 🎨 Clean and simple user interface
* ⚡ Easy task management

## 🛠️ Technologies Used

* **Java** – Application logic
* **HTML5** – Website structure
* **CSS3** – Styling
* **JavaScript** – Dynamic functionality
* **Bootstrap** – Responsive user interface

## 🎯 Project Objective

The main objective of this project is to create a simple task management system that helps users organize their daily activities while gaining practical experience in web development and Java programming.
